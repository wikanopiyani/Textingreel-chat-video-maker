## What it does

Type a chat, pick a style, click **Render**. TextingReel animates the conversation like a real phone, with typing dots, pop-in bubbles, auto-scroll and message sounds, and exports a clean 1080p MP4 you can post straight away.

It runs entirely on your PC. There are no accounts, API keys, credits or monthly plans, so a video costs you nothing beyond the one-time purchase.

## Features

**Chat editor**
- Contact name, status line and profile photo (or initials)
- Keyboard flow: Enter for the next reply, Tab to switch sender
- Drag to reorder, duplicate, delete, undo and redo
- Emoji picker, big emoji, photo messages, date separators and system notes
- Per-message pause (for reaction clips), extra wait and custom time stamps

**Four chat styles.** Bubble Light, Bubble Dark, Green Chat and Social DM. They look like modern messaging apps but are generic designs with no brand names or logos, so your videos stay clear of trademark trouble.

## For developers: full source code

The purchase includes the complete, documented source code, ready to rebrand, translate and extend:

- **Electron** desktop app with context isolation, a sandboxed renderer and a narrow IPC bridge
- **[HyperFrames](https://github.com/heygen-com/hyperframes)** (Apache-2.0) renders HTML compositions to video through headless Chrome and FFmpeg
- Plain JavaScript with **no framework and no bundler**
- **No paid APIs**, so your own product has no running costs
- Windows installer build (electron-builder), automated tests and HTML documentation
- Every interface string in one file for easy translation
